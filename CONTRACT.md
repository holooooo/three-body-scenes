# Three-Body Scenes — internal contracts

Fan-made interactive restorations of three moments from the *Three-Body Problem* trilogy:
`guzheng` (Operation Guzheng), `droplet` (Doomsday Battle), `foil` (two-dimensionalization of the Solar System).
Static site, no build step: ES modules + an importmap pointing at `vendor/three/`.

## Layout

| Area | What lives there |
| --- | --- |
| `index.html`, `scene.html`, `film.html`, `src/**`, `brand/**`, `assets/**` | the site: visuals, UI, camera direction |
| `films/cues/*.json` | picture-synced cue sheets for the three scores |
| `tools/render.mjs`, `tools/cdp.mjs`, `tools/serve.mjs`, `tools/make_film.sh`, `tools/test/**` | frame-exact film renderer and mux |
| `tools/audio/**` | procedural score (Python, numpy/scipy) |
| `tools/deploy.sh`, `tools/*sheet.sh` | site assembly/deploy and review contact sheets |
| `build/**` | generated, git-ignored (`build/audio/<id>.wav`, `build/video/<id>.mp4`, `build/stills/`, `build/site/`) |
| `out/**` | final films, git-ignored |

## Film page contract (page → renderer)

`film.html?s=<id>&render` where `<id>` ∈ `guzheng | droplet | foil`.

- `window.READY === true` once the scene is loaded and the first frame can be drawn.
- `window.DURATION` — film length in seconds (62.0 for all three).
- `window.renderFrame(t)` — returns a Promise; when it resolves the canvas **and** the HTML overlay
  show exactly the frame for time `t` seconds. It is stateless: any `t` can be requested in any order,
  from any number of parallel pages.
- `window.FILM_ERROR` — set to a string if the scene failed to initialise.
- Viewport is 1920×1080 CSS px at devicePixelRatio 1.

## Audio contract (cue sheet → wav)

`films/cues/<id>.json` → `build/audio/<id>.wav`: 48 kHz, 16-bit stereo, exactly `duration` seconds,
integrated loudness about −14 LUFS, true peak ≤ −1 dBFS. No voice. Fully original, synthesized in code.

Cue sheet fields:

- `duration` seconds.
- `direction` — prose brief for the piece (instrumentation, key, feeling).
- `sections[]` — `{ t, name, level, note }`; `level` 0 = near silence, 1 = sparse, 2 = building, 3 = full, 4 = peak.
  A section lasts until the next one starts.
- `hits[]` — `{ t, kind, gain }` picture-synced accents, `t` is the frame-accurate moment of the event.
  `kind`: `sub` (low boom), `impact` (big cinematic hit), `glass` (cold high ping), `pluck` (single plucked string),
  `boom` (explosion-like thump, softer than impact), `swell` (soft bloom of the pad peaking at `t`).
- `risers[]` — `{ from, to }` tension build that must peak and cut exactly at `to`.
- `silences[]` — `{ from, to }` everything but reverb tails ducks hard.

The cue times may change after the camera tracks are finalised; the score must be regenerated by re-running
one command, with no hand edits.
